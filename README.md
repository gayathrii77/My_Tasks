CodeAlpha Hangman Game

A simple text-based Hangman game developed in Python as part of the CodeAlpha Python Programming Internship.

📌 Project Overview

The Hangman Game allows the player to guess a randomly selected hidden word one letter at a time.

The player has a maximum of 6 incorrect guesses. The game continues until the player guesses the complete word or reaches the maximum number of incorrect guesses.

✨ Features
Randomly selects a word from a predefined list
Allows the player to guess one letter at a time
Displays correctly guessed letters
Tracks incorrect guesses
Limits incorrect guesses to 6
Detects repeated guesses
Validates user input
Displays winning and game-over messages
🛠️ Technologies Used
Python 3
random
Lists
Strings
while loops
if-else conditions
Console input/output

▶️ How to Run

Open the terminal inside the project folder and run:

python hangman.py

🎮 How to Play
Run the program.
The game randomly selects a hidden word.
Enter one letter when prompted.
Correct letters are revealed.
Incorrect guesses reduce your remaining chances.
Guess all letters to win the game.
The game ends after 6 incorrect guesses.

        HANGMAN GAME
